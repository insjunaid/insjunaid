## 🗺️ How I Approach a Problem

```
  IDEA ──▶ EDA / DATA AUDIT ──▶ BASELINE MODEL ──▶ AGENTIC / RAG LAYER ──▶ EVAL LOOP ──▶ SHIP
   │             │                    │                    │                 │           │
  spark      "what's the        "does the           "can it reason,     "does it     "does it
             signal here?"       simplest thing       retrieve, act?"     actually     survive
                                  work?"                                  work?"       real users?"
```

I'd rather ship a boring baseline that works than a clever pipeline that
only works in a notebook — then layer in the agentic/RAG complexity once
the baseline earns it.
